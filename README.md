# 🗺️ WebGIS Population Distribution System – Demak Regency 2025

A Geographic Information System (GIS) application built to map, analyze, and visualize population distribution, population density, and annual population growth rate across 14 sub-districts in Demak Regency.

---

## 📌 Project Highlights & Research Novelty
* **Multi-Variable Integration:** Integrates three core demographic variables simultaneously: Total Population, Population Density, and Population Growth Rate.
* **Spatial Classification:** Employs the **Natural Breaks (Jenks)** classification method via QGIS to group thematic map layers accurately.
* **Interactive Dashboard:** Interactive choropleth map with click-to-view detail pop-ups, dynamic bar charts, and annual data filters.
* **Development Methodology:** Built using the **Waterfall Iterative** software development cycle.
* **Publication:** Published in *Router: Jurnal Teknik Informatika dan Terapan*, Vol. 3, No. 4, December 2025.

---

## 🛠️ Tech Stack & Data Sources
* **Geospatial Processing:** QGIS 2.18 (Attribute Joining, Jenks Natural Breaks classification, Shapefile processing).
* **Web Technology:** WebGIS, HTML5, CSS3, JavaScript, Leaflet.js / OpenStreetMap API, Ina-Geoportal Integration.
* **Data Sources:** 
  * **Spatial Data:** Administrative boundaries of Demak Regency sub-districts.
  * **Non-Spatial Data:** BPS (Central Bureau of Statistics) Demak Regency demographic data.

---

## 📊 Key Demographic Insights Found
* **Uneven Distribution:** Highest population & density concentrated in urban/industrial zones (**Demak Kota, Karangtengah, Sayung**), while coastal regions (**Wedung, Bonang**) display significantly lower density.
* **Growth Rate:** Highest annual population growth rate recorded in **Karangtengah Sub-district (0.80% - 1.25%)**.
